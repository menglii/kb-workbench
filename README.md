# 经纬 · 知识工作台

**让知识，有下一步。**

经纬是一个 Obsidian 知识工作台插件，将笔记管理、办公整理、AI 助手和学习回顾放在同一个工作空间。集中查看和批量整理笔记，通过 AI 将已有内容转化为可继续使用的知识。

**2026 华为智创杯 AI 应用创新大赛参赛作品 · 参赛小组：特别厉害的队**

当前版本：`0.1.0`。本仓库提供脱敏后的源码、构建与测试工具，以及产品设计和参赛说明。

## 核心能力

| 场景 | 能力 |
| --- | --- |
| 工作更顺手 | 首页模块排布、全部笔记、多选与批量处理、待处理提醒、看板 |
| AI 接上工作 | 自然语言对话、检索知识库、提出文档操作方案，经确认后执行 |
| 从记录到掌握 | 生成和编辑知识卡、安排学习回顾、查看笔记关联 |
| 整理有退路 | 重要写操作预览与确认，配合快照、撤销和还原；拖拽即时生效并提供撤销 |

笔记仍使用普通 Markdown 和 YAML。AI 需要自行配置服务地址、模型与 API key；相关请求会发送到用户选择的服务。首次使用请先在知识库副本中体验。

## 构建与安装

需要 Node.js 24（见 `.nvmrc`）和 npm，插件要求 Obsidian 1.13.0 或更新版本。主要验证环境为 Windows 桌面，移动端需单独验证。

```bash
npm ci
npm run build
```

将构建后的 `main.js`、`manifest.json`、`styles.css` 及整个 `assets/` 目录，复制到 `<你的知识库>/.obsidian/plugins/kb-workbench/`，再从 Obsidian 社区插件设置启用「经纬」。配图请一并复制。构建产物不提交到源码仓库。

## 开发与验证

```bash
npm run typecheck     # TypeScript 类型检查
npm run lint:probe    # 探针脚本与冒烟清单自检，不操作 Obsidian
npm run build        # 打包插件和样式
npm test             # 离线全量：合成夹具 + Obsidian 桩 + 真实调用链
npm run test:shards  # 使用独立临时目录分片运行全量套件
```

普通全量和分片全量任选其一，不要同时启动。历史全量验收为 1403 / 1403（2026-10-13），验证条件和未覆盖项见[效果佐证](参赛-效果佐证.md)。离线测试不能代替 Obsidian 内的真实交互验证。GitHub Actions 执行类型检查、探针脚本自检、构建和离线测试。

## 开发边界

动文件统一经过 `src/services/mover.ts`，菜单经过 `src/ui/menu.ts`，写操作确认经过 `src/ui/confirm.ts`（拖拽按既有即时生效与撤销规则处理）。请先在测试知识库验证，再决定用于真实资料。
