# 开发指南

## 构建与测试

使用 Node.js 24，在仓库根目录执行：

```bash
npm ci
npm run build
npm run typecheck
npm run lint:probe
npm test
```

也可用 `npm run test:shards` 分片运行全量测试。普通全量与分片全量不要同时启动。

## 安装与探针

将 `main.js`、`manifest.json`、`styles.css` 和 `assets/` 复制到 `.obsidian/plugins/kb-workbench/`，启用或重新加载插件。

部署与真机探针需要配置 `KBW_VAULT_SANDBOX`（测试库）、`KBW_VAULT_REAL`（真实库）和 `KBW_OBSIDIAN_EXE`（程序路径）。路径规则见 `scripts/vault-guard.mjs`；先在测试库验证。

## 源码打包

`node scripts/make-public-pack.mjs --out <输出父目录>` 生成源码包，已有目标不会覆盖。

其他资料见[文档目录](README.md)。
